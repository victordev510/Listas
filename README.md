# Listas
______________________________________________________________________________________________________________________________________________________________________
📋 Sobre o Projeto

O projeto Manipulação de Listas em Python foi desenvolvido com o objetivo de demonstrar o funcionamento de listas, uma das estruturas de dados mais utilizadas na programação. O programa realiza operações básicas como adicionar, exibir e remover elementos, permitindo compreender de forma prática como os dados podem ser armazenados e organizados.

Durante a criação do projeto, foram utilizados conceitos fundamentais da linguagem Python, como listas, laços de repetição (for), métodos de manipulação de dados (append() e remove()), além da exclusão de elementos por índice utilizando o comando del.
______________________________________________________________________________________________________________________________________________________________________

⚙️ Descrição do Projeto

O sistema cria uma lista contendo nomes de pessoas e demonstra diferentes formas de acessar e exibir seus elementos. Inicialmente, os nomes são adicionados à lista e exibidos tanto de forma completa quanto individualmente por meio de seus índices.

Em seguida, é utilizado um laço de repetição para percorrer todos os itens da lista e apresentar cada nome armazenado. O programa também mostra como remover elementos pelo valor e pelo índice, atualizando a lista após cada alteração e exibindo os resultados ao usuário.

Esse projeto contribui para o aprendizado sobre estruturas de dados, manipulação de coleções e lógica de programação, servindo como uma introdução prática ao gerenciamento de informações em Python.
